# SoleVision — Product Reviews & Ratings Roadmap (v2, corrected)

**Feature:** Product Reviews & Ratings
**Status:** Planning — ready to implement
**Supersedes:** `PRODUCT_REVIEWS_ROADMAP.md` (v1) — this version fixes a purchase-verification
security gap, a storage bucket choice, a type mismatch, and adds missing edit/cleanup logic.

---

## What Changed from v1 (read this first)

| Issue | v1 problem | v2 fix |
|---|---|---|
| **Purchase verification (critical)** | INSERT policy only checked `auth.uid() = customer_id` — anyone could review any product, and `is_verified` was set from a client-supplied `orderId` with no server check | INSERT policy now requires a matching completed order via `EXISTS`; `is_verified` is derived automatically by the policy passing, not trusted from the client |
| **Order ID type** | Service passed `String? orderId` into a `BIGINT` column | Standardized to `int? orderId` throughout; **verify `orders.id`'s actual type in your schema before locking this in** |
| **Storage bucket** | Reused `avatars` bucket for review photos | Dedicated `review-images` bucket, mirroring the `product-images` pattern |
| **Editing reviews** | Listed in Phase 6 checklist but never implemented — no `updateReview()`, no `updated_at` column | `updateReview()` added to service + provider, `updated_at` column + trigger added |
| **Storage cleanup on delete** | `deleteReview()` removed the DB row but left orphaned files in Storage | `deleteReview()` now also removes the review's files from `review-images` |
| **Review gating decision** | Ambiguous — button gated on `hasReviewed`, but nothing actually required a purchase | Explicit decision: **verified-purchase-only reviews** (see below). Change this in one place if you'd rather allow unverified reviews. |

**Decision locked for this plan: only customers with a completed order containing the product can
review it.** If you'd prefer to allow anyone to review (Amazon-style, unverified reviews permitted),
say so and I'll strip the `EXISTS` clause back out — but that's a product decision, not a default.

## Phase 1: Database & Backend (Day 1)

### 1.1 Migration File
**File:** `supabase/migrations/20260717_product_reviews.sql`

```sql
-- =========================================
-- PRODUCT REVIEWS
-- =========================================

CREATE TABLE IF NOT EXISTS public.product_reviews (
  id              BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  product_id      TEXT NOT NULL REFERENCES public.products(id) ON DELETE CASCADE,
  customer_id     UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
  order_id        BIGINT REFERENCES public.orders(id) ON DELETE SET NULL, -- confirm orders.id type matches
  rating          INTEGER NOT NULL CHECK (rating >= 1 AND rating <= 5),
  title           TEXT,
  body            TEXT NOT NULL CHECK (char_length(body) >= 10),
  is_verified     BOOLEAN NOT NULL DEFAULT true, -- always true; RLS only allows purchasers to insert
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- One review per product per customer
CREATE UNIQUE INDEX IF NOT EXISTS idx_reviews_product_customer
  ON public.product_reviews(product_id, customer_id);

CREATE INDEX IF NOT EXISTS idx_reviews_product_id ON public.product_reviews(product_id);

-- product_review_images
CREATE TABLE IF NOT EXISTS public.product_review_images (
  id              BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  review_id       BIGINT NOT NULL REFERENCES public.product_reviews(id) ON DELETE CASCADE,
  image_url       TEXT NOT NULL,
  display_order   INTEGER NOT NULL DEFAULT 0
);

CREATE INDEX IF NOT EXISTS idx_review_images_review_id ON public.product_review_images(review_id);

-- updated_at auto-touch
CREATE OR REPLACE FUNCTION public.touch_review_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_reviews_touch_updated_at
  BEFORE UPDATE ON public.product_reviews
  FOR EACH ROW EXECUTE FUNCTION public.touch_review_updated_at();

-- =========================================
-- RLS
-- =========================================

ALTER TABLE public.product_reviews ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.product_review_images ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Reviews are viewable by everyone"
  ON public.product_reviews FOR SELECT USING (true);

CREATE POLICY "Review images are viewable by everyone"
  ON public.product_review_images FOR SELECT USING (true);

-- CRITICAL: only allow inserting a review for a product the customer actually purchased
-- (order exists, belongs to this customer, and contains this product)
CREATE POLICY "Customers can insert reviews for purchased products"
  ON public.product_reviews FOR INSERT
  WITH CHECK (
    auth.uid() = customer_id
    AND EXISTS (
      SELECT 1
      FROM public.order_items oi
      JOIN public.orders o ON o.id = oi.order_id
      WHERE o.customer_id = auth.uid()
      AND oi.product_id = product_reviews.product_id
    )
  );

CREATE POLICY "Customers can update own reviews"
  ON public.product_reviews FOR UPDATE USING (auth.uid() = customer_id);

CREATE POLICY "Customers can delete own reviews"
  ON public.product_reviews FOR DELETE USING (auth.uid() = customer_id);

CREATE POLICY "Customers can manage their review images"
  ON public.product_review_images FOR ALL
  USING (
    EXISTS (
      SELECT 1 FROM public.product_reviews
      WHERE id = review_id AND customer_id = auth.uid()
    )
  );
```

> **Before running this migration:** check the actual column type of `orders.id` in your schema
> (`\d public.orders` in psql, or check `schema.sql`). If it's not `BIGINT`, change `order_id`'s
> type here to match — a mismatched FK type will fail to create or silently misbehave.

### 1.2 Denormalized Rating on Products

```sql
ALTER TABLE public.products
  ADD COLUMN IF NOT EXISTS avg_rating   NUMERIC(2,1) NOT NULL DEFAULT 0,
  ADD COLUMN IF NOT EXISTS review_count INTEGER      NOT NULL DEFAULT 0;

CREATE OR REPLACE FUNCTION public.update_product_rating()
RETURNS TRIGGER AS $$
DECLARE
  target_id TEXT := COALESCE(NEW.product_id, OLD.product_id);
BEGIN
  UPDATE public.products SET
    avg_rating = COALESCE(
      (SELECT ROUND(AVG(rating)::numeric, 1) FROM public.product_reviews WHERE product_id = target_id),
      0
    ),
    review_count = (
      SELECT COUNT(*) FROM public.product_reviews WHERE product_id = target_id
    )
  WHERE id = target_id;
  RETURN COALESCE(NEW, OLD);
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_review_change
  AFTER INSERT OR UPDATE OF rating OR DELETE ON public.product_reviews
  FOR EACH ROW EXECUTE FUNCTION public.update_product_rating();
```

## Phase 2: Service Layer (Day 1–2)

### 2.1 `lib/services/review_service.dart`

```dart
class ReviewService {
  ReviewService._();
  static final ReviewService instance = ReviewService._();

  SupabaseClient get _client => Supabase.instance.client;

  static const _bucket = 'review-images';

  /// Get reviews for a product (paginated), newest first.
  Future<List<Map<String, dynamic>>> getReviews(
    String productId, {
    int offset = 0,
    int limit = 20,
  }) async {
    final data = await _client
        .from('product_reviews')
        .select('*, profiles(full_name, avatar_url), product_review_images(*)')
        .eq('product_id', productId)
        .order('created_at', ascending: false)
        .range(offset, offset + limit - 1);
    return List<Map<String, dynamic>>.from(data as List);
  }

  /// Average rating + review count, read from the denormalized product columns.
  Future<Map<String, dynamic>> getRatingSummary(String productId) async {
    final data = await _client
        .from('products')
        .select('avg_rating, review_count')
        .eq('id', productId)
        .single();
    return {
      'avg_rating': (data['avg_rating'] as num?)?.toDouble() ?? 0.0,
      'review_count': (data['review_count'] as num?)?.toInt() ?? 0,
    };
  }

  /// The current user's review for this product, if any.
  Future<Map<String, dynamic>?> getMyReview(String productId) async {
    final userId = _client.auth.currentUser?.id;
    if (userId == null) return null;
    return await _client
        .from('product_reviews')
        .select('*, product_review_images(*)')
        .eq('product_id', productId)
        .eq('customer_id', userId)
        .maybeSingle();
  }

  /// Whether the current user purchased this product and hasn't reviewed it yet.
  /// Mirrors the RLS INSERT check client-side, purely for UI gating (RLS is the real gate).
  Future<bool> canReview(String productId) async {
    final userId = _client.auth.currentUser?.id;
    if (userId == null) return false;

    final existing = await getMyReview(productId);
    if (existing != null) return false;

    final purchase = await _client
        .from('order_items')
        .select('orders!inner(customer_id)')
        .eq('product_id', productId)
        .eq('orders.customer_id', userId)
        .limit(1)
        .maybeSingle();

    return purchase != null;
  }

  /// Submit a new review. RLS enforces purchase ownership server-side —
  /// this will throw a PostgrestException if the check fails.
  Future<void> submitReview({
    required String productId,
    required int rating,
    String? title,
    required String body,
    List<XFile>? images,
  }) async {
    final userId = _client.auth.currentUser!.id;

    try {
      final review = await _client
          .from('product_reviews')
          .insert({
            'product_id': productId,
            'customer_id': userId,
            'rating': rating,
            'title': title,
            'body': body,
            // no client-supplied order_id / is_verified — the DB trusts nothing from the client
            // about purchase status; RLS already guarantees a qualifying order exists.
          })
          .select()
          .single();

      if (images != null && images.isNotEmpty) {
        final reviewId = review['id'] as int;
        await _uploadImages(userId, reviewId, images);
      }
    } on PostgrestException catch (e) {
      if (e.code == '23505') {
        throw Exception('You have already reviewed this product.');
      }
      if (e.code == '42501' || e.message.contains('row-level security')) {
        throw Exception('You can only review products you have purchased.');
      }
      rethrow;
    }
  }

  /// Update an existing review (own review only, enforced by RLS).
  Future<void> updateReview({
    required int reviewId,
    required int rating,
    String? title,
    required String body,
    List<XFile>? newImages,
    List<int>? removedImageIds,
  }) async {
    final userId = _client.auth.currentUser!.id;

    await _client.from('product_reviews').update({
      'rating': rating,
      'title': title,
      'body': body,
    }).eq('id', reviewId);

    if (removedImageIds != null && removedImageIds.isNotEmpty) {
      for (final imageId in removedImageIds) {
        final row = await _client
            .from('product_review_images')
            .select('image_url')
            .eq('id', imageId)
            .single();
        await _deleteStorageFile(row['image_url'] as String);
        await _client.from('product_review_images').delete().eq('id', imageId);
      }
    }

    if (newImages != null && newImages.isNotEmpty) {
      await _uploadImages(userId, reviewId, newImages);
    }
  }

  /// Delete a review, its image rows, and its Storage files.
  Future<void> deleteReview(int reviewId) async {
    final images = await _client
        .from('product_review_images')
        .select('image_url')
        .eq('review_id', reviewId);

    for (final row in (images as List)) {
      await _deleteStorageFile(row['image_url'] as String);
    }

    // Deleting the review cascades to product_review_images rows via FK.
    await _client.from('product_reviews').delete().eq('id', reviewId);
  }

  Future<void> _uploadImages(String userId, int reviewId, List<XFile> images) async {
    final existingCount = await _client
        .from('product_review_images')
        .select('id')
        .eq('review_id', reviewId)
        .count(CountOption.exact);
    var index = existingCount.count;

    for (final file in images) {
      final bytes = await file.readAsBytes();
      final ext = file.path.split('.').last;
      final path = '$userId/$reviewId/${DateTime.now().millisecondsSinceEpoch}_$index.$ext';
      await _client.storage.from(_bucket).uploadBinary(
            path,
            bytes,
            fileOptions: FileOptions(contentType: 'image/$ext'),
          );
      final url = _client.storage.from(_bucket).getPublicUrl(path);
      await _client.from('product_review_images').insert({
        'review_id': reviewId,
        'image_url': url,
        'display_order': index,
      });
      index++;
    }
  }

  Future<void> _deleteStorageFile(String publicUrl) async {
    // Extract the storage path from the public URL and remove it.
    final marker = '/object/public/$_bucket/';
    final idx = publicUrl.indexOf(marker);
    if (idx == -1) return;
    final path = publicUrl.substring(idx + marker.length);
    await _client.storage.from(_bucket).remove([path]);
  }
}
```

**Note on `canReview()`:** this is a *UI convenience* only — it decides whether to show the
"Write a Review" button. The actual security boundary is the RLS `INSERT` policy in §1.1. Never
rely on the client-side check alone.

### 2.2 `lib/providers/review_provider.dart`

```dart
class ReviewProvider extends ChangeNotifier {
  final ReviewService _service = ReviewService.instance;

  List<Map<String, dynamic>> _reviews = [];
  Map<String, dynamic> _ratingSummary = {'avg_rating': 0.0, 'review_count': 0};
  Map<String, dynamic>? _myReview;
  bool _isLoading = false;
  bool _canReview = false;

  List<Map<String, dynamic>> get reviews => _reviews;
  Map<String, dynamic> get ratingSummary => _ratingSummary;
  Map<String, dynamic>? get myReview => _myReview;
  bool get isLoading => _isLoading;
  bool get canReview => _canReview;

  Future<void> loadReviews(String productId) async {
    _isLoading = true;
    notifyListeners();
    try {
      final results = await Future.wait([
        _service.getReviews(productId),
        _service.getRatingSummary(productId),
        _service.getMyReview(productId),
        _service.canReview(productId),
      ]);
      _reviews = results[0] as List<Map<String, dynamic>>;
      _ratingSummary = results[1] as Map<String, dynamic>;
      _myReview = results[2] as Map<String, dynamic>?;
      _canReview = results[3] as bool;
    } catch (_) {
      // surface via a UI error state if desired
    }
    _isLoading = false;
    notifyListeners();
  }

  Future<void> submitReview({
    required String productId,
    required int rating,
    String? title,
    required String body,
    List<XFile>? images,
  }) async {
    await _service.submitReview(
      productId: productId,
      rating: rating,
      title: title,
      body: body,
      images: images,
    );
    await loadReviews(productId);
  }

  Future<void> updateReview({
    required String productId,
    required int reviewId,
    required int rating,
    String? title,
    required String body,
    List<XFile>? newImages,
    List<int>? removedImageIds,
  }) async {
    await _service.updateReview(
      reviewId: reviewId,
      rating: rating,
      title: title,
      body: body,
      newImages: newImages,
      removedImageIds: removedImageIds,
    );
    await loadReviews(productId);
  }

  Future<void> deleteReview(String productId, int reviewId) async {
    await _service.deleteReview(reviewId);
    await loadReviews(productId);
  }
}
```
