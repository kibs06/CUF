# Prompt: UI/UX Review Request for Customer-Side App

## Prompt to Use

> I'm working on the customer-facing side of my app (screens like Home, Store/Catalog, Notifications, Profile, Orders, Checkout, etc.). Please review the current designs/screens you have access to and give me a thorough UI/UX audit. I want you to act as a senior product designer doing a heuristic review.
>
> Please cover the following:
>
> 1. **Overall consistency** — Are spacing, typography, colors, icon styles, and component patterns (buttons, cards, badges, states) consistent across all customer-side screens? Flag any screens that feel visually disconnected from the rest.
>
> 2. **Missing UI elements** — Based on standard patterns for e-commerce / marketplace apps, are there any elements customers would expect but that are missing? (e.g., search bar, filters/sort, empty states, loading states, error states, notification badges, cart icon with item count, wishlist/favorites, ratings/reviews display, promo banners, order tracking progress bar, etc.)
>
> 3. **Navigation & information architecture** — Is it clear how a customer moves between browsing, ordering, tracking, and account management? Are there any dead ends, redundant taps, or confusing flows?
>
> 4. **Feedback & status communication** — Do all actions (adding to cart, placing an order, payment, errors) give the customer clear visual feedback? Are loading, success, and error states designed for every key action?
>
> 5. **Accessibility** — Check color contrast, tap target sizes, font legibility, and whether the app would work well for users with visual or motor impairments.
>
> 6. **Onboarding & empty states** — What happens the first time a customer opens the app, or when a list (cart, orders, notifications) is empty? Are these states designed, or do they need attention?
>
> 7. **Trust & conversion elements** — Are there elements that build customer trust and encourage purchases (reviews, ratings, secure checkout indicators, clear pricing, return/refund policy visibility, estimated delivery times)?
>
> 8. **Mobile usability specifics** — Since this is a mobile app, check thumb-reachability of key actions, size of tap targets, and whether important actions are within easy reach on a one-handed grip.
>
> 9. **Prioritized recommendations** — Give me a prioritized list (High / Medium / Low impact) of what to add, fix, or improve, with a short reason for each.
>
> Please be specific and reference the actual screens/components you can see, rather than giving generic advice.

## How to Use This
- Paste this prompt into your AI assistant that has access to your current designs, prototype, or codebase.
- If the AI can only see certain screens, tell it which ones to focus on first (e.g., "start with Home, Store, and Notifications").
- Ask follow-up questions on any single section above (e.g., "expand on #4 feedback & status communication") if you want deeper detail on one area.
